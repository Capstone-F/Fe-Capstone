# Frontend Agent Rules

## Git Commit Rules

- Commit messages MUST follow the Conventional Commits specification.
- Use prefixes: `feat:`, `fix:`, `refactor:`, `docs:`, `style:`, `test:`, `chore:`.
- Include an optional scope if applicable, e.g., `fix(auth):` or `feat(components):`.
- Always push to the remote branch directly when instructed.
